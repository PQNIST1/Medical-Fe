# [💊 Online Pharmacy Web App – Frontends](https://medical-fe.onrender.com)

[![💊 Online Pharmacy Web App – Frontend](https://i.imgur.com/We9Rj0o.png)](https://medical-fe.onrender.com)

This is the **frontend** part of an Online Pharmacy Web Application. The goal is to allow users to browse, search, and purchase medicine online with ease. It also features a real-time chatbot for customer support.

## 🔥 Features

- 🧾 Browse a wide selection of medicines
- 🔍 Filter and search by name, category, or price
- 🛒 Add to cart and place orders
- 🗓️ **Book medical appointments online**
- 👤 User registration and login
- 💬 Chatbot support for quick help and FAQs
- 📱 Fully responsive design (desktop & mobile)

## 🛠 Tech Stack

- **React.js** – UI library
- **Redux Toolkit** – Global state management
- **React Router DOM** – Routing/navigation
- **Axios** – API requests
- **Tailwind CSS** – Styling
- **Socket.IO** – Real-time communication (chatbot)

## ⚙️ Clone The Project <a name="clone-the-project"></a>

Follow these steps to run the frontend locally:

### 1. Clone the repository
```bash
https://github.com/PQNIST1/Medical-Fe.git
```
```bash
cd Medical-Fe
```
### 2. Install dependencies
```bash
npm install
```
### 3. Start the development server
```bash
npm start
```
By default, it runs on: http://localhost:5173
